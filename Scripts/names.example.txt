# How this file is used:

#     transcription toward these spellings (e.g. canonical fantasy spellings
#     instead of plausible-English mistranscriptions).
#   - pipeline/summarize_session.sh — injected into the LLM's user message so it
#     normalizes any variant spellings the transcript still contains.
#
# Format:
#   - One name per line.
#   - Lines starting with `#` are comments and ignored. Blank lines are ignored.
#   - Leading/trailing whitespace is trimmed.
#   - Section comments (e.g. "# === Player Characters ===") are conventional
#     but not enforced by the scripts; structure however helps you maintain it.
#
# Tips:
#   - Add names freely as new characters / locations appear. A fuller glossary
#     is strictly better — whisper does meaningfully better on names it has seen.
#   - Override path with: NAMES_FILE=/path/to/other.txt ./pipeline/transcribe_audio.sh
#   - Disable name injection entirely: NAMES_FILE=/dev/null ./pipeline/transcribe_audio.sh
